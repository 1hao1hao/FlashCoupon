# FlashCoupon 学习资料导航

准备实习面试，从这里进入。日常只用 [INTERVIEW_CORE.md](INTERVIEW_CORE.md) 建立和复述主线；其他文档按问题查阅，不要求从头读完源码。本轮材料依据当前实现和已有测试工件整理，没有重新压测。

## 1～2 小时阅读路线

| 时间 | 行动 | 必须完成的输出 |
|---|---|---|
| 0～15 分钟 | 读核心 A、B、G，先不点源码 | 脱稿说出业务问题和从受理到券可用的流程 |
| 15～40 分钟 | 读核心 C、D；卡住才查架构“故障窗口” | 解释两个 pending、四个确认/删除阶段、为什么超时不能退库存 |
| 40～55 分钟 | 读核心 E；查双队列“实测结果与负结果”和验收“性能结果” | 用两组不同实验说明收益及代价，不混用负载或 TPS |
| 55～75 分钟 | 读核心 F，遮住答案逐题说 | 每题按“结论 → 原因 → 机制 → 限制”回答 30～60 秒 |
| 75～90 分钟 | 录一轮语音模拟：标准介绍，再随机追问三题 | 找出术语混淆、数字夸大、讲代码而忘记业务的句子 |
| 90～120 分钟（可选） | 只补录音暴露的弱项，查指南第 5/7 节 | 重录介绍及薄弱题，不扩展成源码通读 |

只有一小时：压缩 E 的阅读，保留 A、B、D 和 F 前五题，并至少录一次项目介绍。
